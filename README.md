# switch-mapper
Tired of spinning up massive enterprise IPAM tools just to remember which switch port your living room TV is plugged into? Switch Mapper is the antidote to homelab bloat. It provides a stunning, interactive 16-port dashboard that runs on a single Python file, saves to a simple JSON, and looks perfectly at home next to your Unraid dashboard. Say goodbye to messy spreadsheets!

This was built to solve an issue that I wanted a very simply solution to mapping my network switch.

Features:

🪶 Stupidly Lightweight: No SQL databases or multi-container stacks required. Everything saves to a single local JSON file.

🕶️ Sleek Dark Mode: A completely offline, modern aesthetic built with vanilla CSS.

📱 Responsive Design: Looks great on a desktop monitor and scales perfectly to your phone when you are standing in front of the server rack.

⚡ Frictionless Editing: Just click any port to update the device name, VLAN ID, and connection status instantly.
